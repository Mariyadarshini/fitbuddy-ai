FITBUDDY AI PROJECT DOCUMENTATION

Files in this folder:
- Aim.txt: Project aim.
- Algorithm.txt: Step-by-step algorithm.
- Flowchart.svg: Project flowchart with connected boxes and directional arrows.
- Results.txt: Project results and observed functionality.
- Project_Report.docx: Project report (overview, scenarios, architecture, outputs, conclusion).
- FitBuddy_AI_8_Phase_Project_Documentation.docx / .pdf: Combined 8-phase documentation.

Important project behavior:
- Home page opens first with the planner form.
- A 7-day plan and nutrition / recovery tip are generated from the user's details.
- Users can submit feedback to update the plan.
- Users and plans are stored in a SQLite database.
- If Gemini is unavailable, a local fallback generator is used.
